# AHMED BIN RASHED — أحمد بن راشد

موقع أعمال المصور السينمائي أحمد بن راشد.
Portfolio site for Saudi cinematographer Ahmed bin Rashed.

## البنية

| | |
|---|---|
| `index.html` | الصفحة الرئيسية: البطل ← نبذة عني ← الأعمال ← لقطات ← الختام |
| `work/*.html` | صفحة لكل عمل: بنر ← معلومات ← الفلم أو المعرض |
| `assets/style.css` | التصميم كامل — نظام الألوان في أول الملف |
| `assets/main.js` | حركة الدخول، الظهور عند السكرول، شريط اللقطات، عارض الصور |
| `assets/works.js` | كاروسيل الأعمال |
| `assets/media/` | الأفلام والصور بعد التحويل للويب |

## التشغيل محليًا

أي سيرفر ثابت يكفي — الموقع HTML و CSS و JS فقط، بدون أي بناء أو حزم:

```bash
npx serve .
```

`?ready` في الرابط يتخطى حركة الدخول (للمعاينة وأخذ اللقطات).
